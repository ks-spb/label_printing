# Label Printing

Программа для печати этикеток из PDF или открытия копии BarTender с выбранной этикеткой.

## Описание программы

Для выбора этикетки необходимо ввести артикул или начало имени файла.

Сначала программа ищет файл в локальной папке PDF-этикеток. Если найден один
вариант, он сразу открывается или передаётся в печать. Если вариантов несколько,
программа предлагает выбрать один из них. При отсутствии PDF сохраняется прежний
поиск `.btw` на Yandex.Disk с загрузкой локальной копии и запуском BarTender.

Поиск PDF не зависит от регистра, поддерживает буквы, цифры и знаки. Точное имя
имеет приоритет над совпадениями по началу. Допускается отличие ровно на один
первый ноль: например, запрос `20058` найдёт `020058.pdf`, а `020062` — варианты
`020062-1.pdf` и `020062-2.pdf`.

Список PDF загружается один раз при запуске. Чтобы увидеть новые файлы,
добавленные в папку после запуска, перезапустите программу или заново выберите
её через меню «Папка PDF…».

## Запуск программы

Для работы программы в корне необходимо поместить файл .env для доступа к Yandex.Disk.
Запускается файл label_printing.py.

По умолчанию PDF ищутся в папке:

`D:\Yandex.Disk\Шплинты\Этикетки\Принтер, фасовка\рабочие этикетки\МАРКЕТПЛЕЙСЫ\Этикетки PDF`

На другом компьютере путь может отличаться. Если исходная папка недоступна при
запуске, программа предложит выбрать папку с PDF-этикетками. Выбранный путь
запоминается только для текущего пользователя Windows в
`%LOCALAPPDATA%\LabelPrinting\settings.json`; ключи из `.env` туда не копируются.
Папку можно сменить через меню «Папка PDF…». Необязательная переменная
`PDF_LABELS_DIR` в `.env` остаётся резервным путем для первого запуска. Пустая
доступная папка не считается ошибкой: поиск продолжится через существующий
`.btw`-маршрут.

PDF открывается через приложение, зарегистрированное в Windows. Печать
выполняется на принтер по умолчанию без диалога настроек через встроенный
SumatraPDF. Значение из поля «Кол-во» передаётся одним пакетным заданием: например,
для 20 копий запускается одна печать с параметром `20x,fit`, а не 20 отдельных
процессов. Если встроенный компонент вообще не смог запуститься, программа
использует прежнюю системную команду Windows. После ошибки уже запущенной
пакетной печати автоматического повтора нет, чтобы не напечатать двойной тираж.

BarTender для PDF-печати не требуется. Он проверяется только при переходе к
старому `.btw`-маршруту, когда подходящий PDF не найден, а также при работе с
разделом «Поставки». Если BarTender отсутствует или не настроен, программа
показывает сообщение об ошибке, но это не мешает следующему поиску и печати PDF.

## Установка готовой программы

1. Распаковать `label_printing_1.1.4_setup.zip`.
2. Дважды щёлкнуть `label_printing_1.1.4_setup.exe` и подтвердить установку.
3. После установки на рабочем столе появится ярлык
   **Label Printing 1.1.4 (тест)** с иконкой.
4. Запускать программу двойным щелчком по этому ярлыку.

Установщик не подписан коммерческим сертификатом. Если Windows SmartScreen
покажет предупреждение для этого собранного файла, выбрать **Подробнее**, затем
**Выполнить в любом случае**.

Тестовая версия устанавливается отдельно в `C:\LabelPrinting-1.1.4-test` и не
заменяет рабочую программу в `C:\LabelPrinting`. Обе версии можно запускать
одновременно. У каждой версии отдельный ярлык и отдельное удаление через Windows.

При первой установке тестовая версия копирует `.env` из рабочей установки, если
он существует. Если рабочей установки нет, используется `.env`, вложенный в
установщик. При повторной установке 1.1.4 её собственный `.env` сохраняется.

## Создание установщика

Для сборки нужны Python 3 и Inno Setup 6. Выполнить из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_release.ps1
```

Сценарий создаст виртуальное окружение сборки, соберёт программу с иконкой и
подготовит два файла:

- `release\label_printing_1.1.4_setup.exe` — установщик Windows;
- `release\label_printing_1.1.4_setup.zip` — ZIP с установщиком для переноса.

Файл `.env` берётся из папки `programma` без изменения его содержимого. Не
передавайте готовый установщик посторонним: внутри него находятся рабочие ключи.
